# Coverage ledger

`ledger.json` contains one row per application category. Every row begins **not_started** with zero recorded products. Zero describes this corpus, not the market. No discovery universe, languages, regions or source set has yet been researched, and no market-coverage percentage is defined.

Count discovery sightings, deduplicated products, offerings, primary-sourced products, reviewed products, independently measured products, publication-eligible products and published products separately. Category membership overlaps: deduplicate stable product IDs before aggregating across categories. Do not add feature/module/plan/version counts as additional products without the identity decision.

Near-exhaustiveness is a maintained research goal. For each bounded survey, state source sets, inclusion/exclusion, geographic/language scope, cutoff date, discovery saturation, known blind spots, evidence depth, freshness, rights and receiving delivery. A finite category list is not a known total of all applications. Count projections from actual linked records and actual acceptance receipts; never from the number of planned issues.

The initialization validator checks category alignment, nonnegative counters and logical prerequisites. It cannot prove a source universe complete or replace human evidence review.
